08 / BEFORE YOU ASK

Good questions.
Clear answers.

Technical accuracy is a feature, not fine print.

Can this test any AI agent?+

The lab can test supported reference agents and can evaluate other authorized staging agents through a suitable HTTP adapter. It is not a plug-and-play test of every production agent. Test quality depends on how much behavior and tool execution the integration exposes.

Can I use synthetic data instead of real customer records?+

Yes. The v0.3 local MVP can generate fictional datasets for banking, insurance, healthcare, retail and HR, including UAE/KSA settings. CSV and JSON fixtures can support controlled tests. Do not submit sensitive data through this marketing website.

Is the interactive demo an actual security test?+

No. The public site's demo is a scripted, browser-only explainer. Real tests require an authorized agent endpoint or supported local connector, staging fixtures, instrumentation and analyst review. Demo verdicts are never presented as customer security findings.

Does the score certify an agent as safe or insured?+

No. Risk scores summarize observed exposure and evidence coverage for specific test scenarios. They are not guarantees, compliance certifications, breach probabilities or insurance underwriting ratings.

Is the testing environment fully isolated?+

Not yet. v0.3 is a working local MVP, not a hardened isolated runtime for arbitrary untrusted code. Pilots must use approved staging systems, restricted network access and tools with real-world side effects disabled.

Can your company arrange AI insurance?+

No. This is a proposed technical AI-assurance brand exploring opportunities in the UAE and KSA. It does not offer insurance brokerage, underwriting, certification or regulatory approvals.
